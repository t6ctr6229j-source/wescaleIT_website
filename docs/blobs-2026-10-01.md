Exactly one scene per destination page; no changes to the other brand websites.
Desktop home placement remains unchanged. Mobile canvas dimensions are bounded,
with a mobile composition adjustment rather than the old 360vw canvas.

`js/hero-blob.js` replaces the home page's legacy Webflow/jQuery scene loader.
Runtime version is pinned to 2.0.63. A 20-second load limit leaves the local
poster visible on slow or failed loads. Visibility and reduced-motion changes
pause playback. Initial reduced motion does not request the external runtime.
Local WebP posters are actual transparent renders of the three original scenes,
not recreated artwork. They also work without JavaScript and after WebGL loss.

Validation: local link/image checks, authorship checks, JavaScript syntax,
analytics consent tests and production build. Headless Chromium visual and DOM
checks at desktop 1440px and mobile 390px: one scene, no horizontal overflow,
loaded poster, no uncaught errors. Three additional mobile cases per page:
reduced motion, blocked external animation requests and JavaScript disabled.
Reduced-motion and JavaScript-disabled cases issue no external scene requests.
External render assets in the test browser are served through a cache of the
original HTTPS resources, fetched with certificate validation, because the
test browser does not trust the environment's proxy CA. Real iOS hardware has
not been tested.
